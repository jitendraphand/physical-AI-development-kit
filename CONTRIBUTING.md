# Contributing

This is a *kit* of self-contained projects, not a monorepo application.

- Add a new robot under `projects/<name>/` with CAD (parametric, plus shipped STL/STEP), a cost-friendly India BOM with checked links, a learning curriculum with measurable outcomes, tests, and at least one simulation.
- Do not rewrite or delete an existing project unless you are fixing it.
- Simulation videos must be labelled as renders, never as real footage.
- Prefer the same tools the kit already uses: ROS 2, FreeCAD or CadQuery, Gazebo, PyBullet.

Open a pull request against `main`.
